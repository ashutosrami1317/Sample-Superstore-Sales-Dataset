# Sample Superstore Sales Dashboard (Power BI)

## 📊 Project Title

**Sample Superstore Sales Dashboard using Power BI**

## 📖 Project Overview

This project is an interactive **Power BI Dashboard** built using the **Sample Superstore Sales Dataset**. The dashboard helps analyze sales performance, profit, orders, customer segments, and regional trends. It provides business insights through interactive charts and filters, enabling users to make data-driven decisions.

---

## 🎯 Objectives

* Analyze overall sales and profit.
* Track order quantity and customer performance.
* Compare sales across regions and states.
* Identify top-performing products and categories.
* Visualize business trends with interactive dashboards.
